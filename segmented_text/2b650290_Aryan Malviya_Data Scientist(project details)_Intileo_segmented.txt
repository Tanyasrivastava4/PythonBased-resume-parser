Project Details:-
RAG-based Chatbot (LLaMA 3.1, Qdrant, LangChain, Docker)
Built an on-premises RAG chatbot for the Indian Air Force, integrating Azure Form Recognizer for
PDF text extraction and Qdrant for vector search.
Implemented BGE embeddings with LangChain orchestration, enabling accurate retrieval and secure,
context-aware responses from classified documents.
Deployed on Docker containers, ensuring compliance with security.
Intelligent Document Processing & Evaluation Tool (Azure Form Recognizer, OpenAI, Streamlit,
Python)
Developed an AI-powered document evaluation pipeline combining Azure Form Recognizer for PDF
text extraction and OpenAI models for semantic analysis and scoring.
Built a Streamlit-based user interface to allow real-time document inspection, review, and
evaluation before final submission.
Implemented automated content validation workflows to check compliance, completeness, and
formatting consistency.
Enabled faster and more accurate evaluation of structured and unstructured documents, reducing
manual review time
