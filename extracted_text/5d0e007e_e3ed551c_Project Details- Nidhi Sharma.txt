Project Details:-
1. Healthcare Smart Care Bot (Generative AI Project)
Team Size: 4 members
Project Duration: ~8 weeks
Project Summary:
The Healthcare Smart Care Bot is a Generative AI–based assistant designed to support
users with healthcare-related queries such as symptom guidance, general medical
information, and personalized responses using trusted data sources. The main objective was
to create a reliable, context-aware AI system that avoids hallucinations and provides accurate
information.
My Role & Contributions:
• Fine-tuned Large Language Models (LLMs) using Hugging Face Transformers for
healthcare-related queries.
• Implemented Retrieval Augmented Generation (RAG) using LangChain to fetch
verified medical information before generating responses.
• Performed data preprocessing and prompt engineering to improve response relevance
and accuracy.
• Integrated the model into a Flask-based web application for real-time interaction.
• Collaborated with team members on model evaluation, testing, and optimization.
Tech Stack:
Python, Hugging Face Transformers, LangChain, NLP, LLMs, RAG, Flask, Pandas, NumPy
